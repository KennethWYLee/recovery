# 教師排序入口

- 使用者找不到教師排序。讀取 CourseWorkspace、QuestionActions、TeacherRankingPanel、排序初始化與後端作答權限；教師排序原本只出現在 ranking 階段，其他階段缺少入口說明。
- 每題標題下新增教師排序狀態；作答及展示階段說明先按「開放個人排序」。ranking 階段且有權限時提供跳至教師排序區的連結，已送出時顯示查看／修改。截止及公布階段顯示符合現有流程的說明。
- 排序操作提示改為按上下箭頭調整名次；保留既有拖曳及送出行為。定位目標可取得焦點並預留固定標頭空間，入口可換行。
- npm run gate:static 通過；npm run gate:build 建置與 4 項產物檢查通過。臨時 React 靜態渲染检查覆盖 6 個階段 × 2 種權限，共 12 種組合，僅開放排序且有權限時存在操作連結。
- 沒有變更後端排序流程或正式課堂資料；未重跑後端 API 模擬，未代教師提交排序。建立提交並推送原 Sites 來源庫後部署原正式站。
