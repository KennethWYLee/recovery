# 首頁與課程頁 QR code

- 使用者要求首頁角落或按鈕顯示該課程 QR code。讀取首頁導向、課程清單、課程頁常駐代碼、既有 QRCodeSVG 依賴及加入課堂路由。
- 新增 CourseJoinQrButton；首頁管理員在有進行中課堂的課程旁可點 QR code，開啟時讀取最新課堂與代碼。課程頁代碼旁也可直接開啟。
- 使用原加入路由 /join/{joinCode} 及目前網站 origin；顯示 288px 黑白 QR code、四格留白、六位代碼，可縮放適應手機寬度。原生 dialog 支援關閉按鈕、Escape 及焦點返回。
- 首頁讀取超過 15 秒或課堂未開放加入時顯示錯誤。沒有變更課堂開放設定、學生資料或其他作答流程。
- npm run gate:static 通過；npm run gate:build 建置與 4 項產物檢查通過。未重跑未變動的後端 API 模擬；未代學生掃碼報到。
- 建立來源提交並推送原 Sites 來源庫、部署到原正式站；上線後以瀏覽器檢視對話框，不提交課堂資料。
