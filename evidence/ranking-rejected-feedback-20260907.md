- 讀取排名 PUT 路由、submitClassroomRanking、guardedClassroomRankingBatch、applySnapshot、學生畫面與參與報表。
- 正式排名提交表完整分頁查詢顯示本題只有一名學生的兩個版本及教師一份；舊 classroom_ranking_submissions 表為空。
- 透過已登入管理員的 /observability 頁面取得近期失敗：

  - 2026-09-07 12:14（Asia/Taipei），相同路由及錯誤，req-d532c330-2052-4831-aa22-5b849b936faa。
- 正式 audit 記錄顯示本題在 04:12:48.190Z 從 ranking 轉為 locked，在 04:41:27.106Z 公布。
- 以上證實有排序送出被拒收；營運頁未顯示這兩筆請求的學生身分，不能據此逐筆確定與姓名的對應。
- Worker 近期日誌未包含當時請求，沒有把日誌缺少紀錄解讀為未操作。
- 目前成功提示須等 API 回應成功後才設定；未找到直接在點擊時假報成功的程式。既有失敗訊息在頁面上方，學生於下方操作時可能未看見。

## 修改

- 新增 StudentActionFeedback：學生操作結束時將焦點與畫面帶到成功或失敗提示，避免訊息留在視窗外。
- 排序未開放的 API 錯誤明示本次未保存。
- 學生鎖定畫面區分自己的排序是否已保存。
- 教師參與表於截止後改為「未收到（已截止）」，不再暗示仍可送出。
- 下修品質設定中因抽出提示而降低的函式行數／複雜度基線。
