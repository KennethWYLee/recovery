# 在學生表格調整組別與發言人

## 範圍與實作

- 使用者要求下方表格顯示誰是發言人，並直接調整組別與發言人。依既有指定代表的權限實作，說明及用語記錄於 PROJECT.md。
- 已讀取參與報表、課堂快照、PATCH 管理路由、moveClassroomParticipant、setClassroomRepresentative、歷史分組規則、表格樣式及 API 模擬流程。
- ParticipationRows 顯示目前組別下拉選單、發言人標示及「設為發言人」按鈕。組別尚無發言人時明示需要指定；未分組學生不可指定為發言人。
- StudentParticipationPanel 沿用既有管理 PATCH 路由，保存完成後重新讀取報表；操作期間禁止重複點擊，舊讀取結果不能覆蓋調整後資料，錯誤留在表格上方。
- 參與報表新增學生報到紀錄 ID、目前組別 ID、目前發言人與課堂階段，僅原管理員報表可讀取。
- useWorkspaceLoader 的更新判斷納入學生組別及各組發言人，讓其他教師畫面也能同步這些調整。
- 測試發現既有示範識別碼短於原驗證下限。_shared.ts 額外接受既有 24 名示範學生及 6 組的精確識別碼格式；後端仍驗證學生、小組及課堂歸屬。
- 沿用既有換組規則：只更新作答中的題目及後续題目；已公布題目的分組紀錄不回寫。移走發言人會清除原組的指定，教師需重新指定。

- 使用者回報換組後發言人按鈕也應調整。檢查表格後，發現成功操作仍等待第二次報表讀取才更新。
