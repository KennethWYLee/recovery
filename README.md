# 課堂小組回應與排序系統

本系統支援教師在同一堂課中連續新增問題，讓學生以小組共同回答，再以個人身分完成其他小組回答的完整排序。

## 目前功能

- 課程建立、修改名稱與刪除。
- 每次課堂指定組數，學生輸入六位課堂代碼後先進入等待區。
- 教師確認到齊後一次隨機平均分組，並可拖曳調整組員及指定小組代表。
- 遲到學生自動加入當下人數最少的組；加入時點決定是否能參與目前問題。
- 一堂課可建立多個問題；同一時間只開放一題進行作答、展示或排序。
- 每組只有指定代表可編輯共同回答。
- 每位學生完整排列其他組的回答；第一名獲得最高分、最後一名獲得最低分，系統以平均分數由高到低排名並保留名次分布。
- 排序結束後先鎖定結果，教師確認並公布後學生才能查看。
- 每題保留分組快照、回答、個人原始排序、版本與操作紀錄。
- 教師可隨時調整一般課堂設定；完成分組後不能更改組數。
- 六位課堂代碼為主要加入方式，QR Code為選用功能。
- 系統管理員審核 `@ntub.edu.tw` 帳號後才可使用；管理員帳號在伺服器端設定。
- CSV匯出包含整堂課所有問題、回答與原始排序。

系統會為管理員建立一門標示為虛擬資料的示範課程，其中包含24位虛擬學生、6組、兩題已公布結果及一題作答中的資料。

## 本機執行

需要 Node.js 22.13.0 以上版本。

```powershell
npm install
Copy-Item .dev.vars.example .dev.vars
npm run dev
```

## 檢查

```powershell
npm run gate:ci
npm run test:unit:coverage
npm run audit:production
```

資料庫結構由 `drizzle/` 內的遷移檔維護；執行期間只驗證結構，不自行修改正式資料庫結構。
